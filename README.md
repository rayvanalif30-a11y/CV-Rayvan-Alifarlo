# Rayvan Alifarlo Mahesworo: CV

An interactive CV: a paper sheet that comes apart into layers as you scroll, then turns over to the contact side.
A **Plain view** button shows it as an ordinary page.

`index.html` is the whole site in one self-contained file (fonts, photo, and logos are inlined), so it can be hosted anywhere as a static page.

## Editing

- `src/cv-src.html`: the page, with placeholders for fonts, images, and the engine
- `src/assets/`: photo, logos, fonts
- `src/engine/`: the open-source scroll-craft engine
- `src/build.py`: rebuilds `index.html`; the portfolio address is set at the top

```bash
python src/build.py
```
